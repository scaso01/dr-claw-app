## Notes

### android-mcp MCP Issue
The `android-mcp` (uvx) MCP server showed "Connected" but its 9 tools never surfaced as callable.
Root cause: Claude Code issue #25081 — MCP SDK 1.26.0+ adds `outputSchema`, `annotations`, `instructions`
fields in protocol responses that Claude Code silently drops all tools for.

### Resolution
Built custom `emu-mcp.py` MCP server wrapping uiautomator2 with low-level `mcp` SDK pinned to `<1.20`.
13 tools, clean protocol response (no outputSchema/annotations). Verified end-to-end.
Registered as `emu-mcp` in `~/.claude.json`. Available in new sessions.

### Testing Methodology
- Used `emu-tap.py` CLI wrapper (uiautomator2) via Bash tool for all interactions
- XML hierarchy dumps for element discovery (53KB per dump, ~30 elements visible)
- Coordinate-based tapping with smart element matching (text → desc → resource-id fallback)
